# TenderPulse market snapshot

This directory is generated by `npm run data:full`, `npm run data:sync`, or `npm run data:import`.

- `manifest.json` describes coverage and available partitions.
- `partitions/<year>/<sub-ou>.json` contains classified award rows used by the dashboard and Excel exports.
- `daily-changes.json` contains the most recent new, changed, and removed record IDs for future alerts.

Run `npm run data:full -- --date-from 2023-01-01 --date-to YYYY-MM-DD` once to create the complete baseline. Daily syncs update that baseline afterward. Dense portal date ranges are split automatically when the portal reaches its 10,000-row response cap. The dashboard falls back to keyword-based live portal searches while the manifest status is `empty`; those fallback searches are not a substitute for the complete baseline.
